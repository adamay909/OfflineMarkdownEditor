About this app

This is a webapp for editing local files and it can work entirely offline. It works best with browsers based on Chromium like: Chromium itself, Google Chrome, Microsoft Edge, Brave. You can install this as an app (there is a button next to the address bar or thereabouts) and it will behave reasonably close to a real desktop application, or mobile app on Android.

The Markdown editor is EasyMDE avaiable at: https://github.com/Ionaru/easy-markdown-editor/tree/master.
